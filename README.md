# Evolution Auto — Homepage

Premium EV homepage built with plain HTML, CSS and vanilla JavaScript (no frameworks or libraries).

```
index.html   markup for every section
style.css    design tokens, layout, animations, responsive rules
script.js    scroll engine, reveals, gallery, explorer filter, brands, cursor
assets/      images/  vehicles/  brands/  icons/
```

Open `index.html` directly, or serve the folder (e.g. `npx serve .`).

**Before launch:** the photography in `assets/` is placeholder stock imagery (Unsplash) and shows
non-Evolution vehicles — replace it with official model photography. Partner tiles, contact
details and the accent colour (`--accent` in `style.css`) are also placeholders to confirm.
